🤖 RAG Chatbot using GROQ & LangChain

## 📌 Project Overview

This project implements a **Retrieval-Augmented Generation (RAG)** system that enhances Large Language Models (LLMs) with external knowledge.
It retrieves relevant documents and generates **accurate, context-aware responses**.

---

## 🚀 Features

* 🔍 Semantic Search using embeddings
* 📄 Document Retrieval from custom data
* 🤖 LLM-powered response generation (GROQ API)
* ⚡ Fast inference using GROQ
* 🔗 Integration with LangChain

---

## 🧠 How RAG Works

1. User asks a question
2. System searches relevant documents
3. Retrieved data is sent to LLM
4. LLM generates context-aware answer

---

## 🛠️ Tech Stack

* Python
* LangChain
* GROQ API
* Vector Databases (FAISS / Chroma)
* NLP & Embeddings

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone https://github.com/Hamidshaik/RAG-Chatbot-GROQ.git
cd RAG-Chatbot-GROQ
```

### 2️⃣ Create Virtual Environment

```
python -m venv venv
venv\Scripts\activate
```

### 3️⃣ Install Dependencies

```
pip install -r requirements.txt
```

### 4️⃣ Add API Key

Create `.env` file and add:

```
GROQ_API_KEY=your_api_key_here
```

---

## ▶️ Run the Application

```
python app.py
```
